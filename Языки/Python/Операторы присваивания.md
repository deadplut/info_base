- создают ссылки на [[Объект в Python|объекты]]
- имена создаются при первом присваивании
- некоторые операции неявно выполняют присваивание 

### Пример

```
x = 1

spam = ham = 'asdasd'
```

### Распаковывающие последовательность операторы
- Любой итерируемый объект можно присвоить поэлементно
- кол-во элементов и переменных долнжо быть равно
```
x, a = 1, 2
[x, a] = [1, 2]
a, b, c, d = 'spam'
a, *b = [1, 2, 3, 4] # расширенная
```

- при расширенная последовательности переменной со звездочкой присвоится [[Списки|список]] - `b` выведет `[2,3,4]`
